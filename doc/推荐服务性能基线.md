# 在线关键词推荐性能基线

采样日期：2026-10-10。本报告记录一组本机开发环境数据，供后续优化做同条件对照，不代表生产容量或长期稳定性。

## 复现条件

- 机器：x86_64，Intel Core i7-12650H；当前环境 `nproc` 为 6。
- 构建：CMake `Debug`，C++11；服务使用 `conf/myconf.conf` 的 4 个工作线程、队列容量 10、每连接在途上限 16。
- 词库：`en_dict.dat` SHA-256 `39c0be730884aa184625aa6e1875ebf2837a2a028f5dd996e2bf9c194931178f`；`en_index.dat` 为 `19c6b655acdcd8113b7c05fbfe5d214eaeb3a22b49ffc578b345c12c3426a927`；`cn_dict.dat` 为 `96908a6da88f74aa991b0b29ca7614475600ec0fd0ef39ec7a242ddacfcb667e`；`cn_index.dat` 为 `eabe005706dfa24941b8e97f48c93e66ad1b17e58b6ed39d71f65cd05cf890a2`。
- 工具：[benchmark_recommendation.py](../scripts/benchmark_recommendation.py) 自动启动本地服务，4 条持续连接，每条先预热 2 次；随后共发出 160 次请求，每条连接一次只等待一个请求响应。按 `request_id` 校验 TLV 响应，统计客户端往返时间。候选数另用 `recommend_keywords` 对同一词库逐词查询。

```bash
cmake --build build -j 4
python3 scripts/benchmark_recommendation.py --requests 160 --concurrency 4 --warmup 2
```
