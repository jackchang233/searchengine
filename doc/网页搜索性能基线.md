# 在线网页搜索性能基线

采样日期：2026-10-11。本报告只是一组本机开发环境数据，供同条件回归比较，不代表生产容量。

## 复现条件

- CMake `Debug`、C++11，Intel Core i7-12650H；当前容器可用 6 个逻辑处理器。
- 服务使用 `conf/myconf.conf`：4 个工作线程、队列容量 10、每连接在途上限 16。
- 网页快照为 `data/web_index/CURRENT` 指向的 `gen-DPkmhR`：3,841 篇文档、97,061 个词项、1,048,882 条 posting。服务启动时校验快照和当前 cppjieba / 停用词资源指纹。
- 测试工具建立 4 条持续 TCP 连接，每条预热 2 次，再发送共 160 次 TLV 类型 2 请求；每连接同一时刻只等待一个响应，按 `request_id` 校验返回。查询轮转为 `中国`、`经济`、`国际`、`人民网`、`科技`、`新闻`、`alpha`、`不存在词项`，`top_k=5`。

```bash
cmake --build build -j 4
python3 scripts/benchmark_recommendation.py --operation search --requests 160 --concurrency 4 --warmup 2
```
